# Changelog

All notable Marketplace changes are documented here. Module versions retain the
Odoo major prefix and use the final component for compatible listing and data
module updates.

## 19.0.1.0.8 / 18.0.1.0.8 / 17.0.1.0.8 / 16.0.1.0.8 — 2026-08-16

- Replaced the legacy Marketplace gallery image with the current field invoice
  printing artwork.
- Added credential, least-privilege, revocation, and data-handling guidance.
- Added connection troubleshooting and supported-version lifecycle documentation.
- Added automated validation for Marketplace images, links, markup, and branch
  parity.
- Added a real Odoo installation screenshot and made the top-level launcher
  open the authenticated inSitu Sales application directly.
- Documented the legacy XML-RPC transport audit and JSON-2 migration plan.
